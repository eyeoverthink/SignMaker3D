## Troubleshooting

**"Font file not found"**
- Make sure the .ttf file is in the FONTS folder
- Check the filename matches exactly (case-sensitive)
- Try using Windows built-in fonts first

**"Symbol renders as blank square"**
- Font doesn't have that Unicode character
- Try Symbola (has everything) or Noto Sans Symbols 2

**"Font name doesn't work in OpenSCAD"**
- Try the exact font name from the font file properties
- Right-click font → Properties → Details → Title
